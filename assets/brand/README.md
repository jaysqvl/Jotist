# Jotist brand assets

The approved mark pairs the indigo audio symbol with a rounded lowercase `jotist` wordmark. Normal prose uses **Jotist**.

- Primary indigo: `#6356E5`
- Audio accent: `#22C7D8`
- Lettering on light backgrounds: `#171923`
- Lettering on dark backgrounds: `#F7F7FB`

The light/dark SVG lockups use the same embedded generated artwork and layout. The full lowercase j, including its dot and descender, and the symbol each occupy 96 units of vertical space. `geometry.json` records the measured source bounds and final layout. These are self-contained SVG layout wrappers around raster artwork, not traced vector paths.

`jotist-icon.png` has a transparent exterior and an opaque white inner speech bubble. Keep its cyan center bar. Use the provided light/dark lockups rather than changing the symbol's colors for dark mode.

The source artwork was prepared using built-in image generation; the exact prompts are in `generation-prompts.json`. Production copies are under both web applications' public directories. The earlier targeted logo screen identified a related flame/speech-bubble motif used by CampfireFM; these assets are the user's selected design direction, not a claim of trademark clearance.
